# Calendario lunar

Calendario lunar en español para San Francisco del Oro, Chihuahua. Muestra la fase e iluminación de la Luna, las fechas de las cuatro fases principales y una estimación de salida y puesta lunar.

## Uso sin conexión

Abre index.html directamente en un navegador. La página no necesita servidor, instalación ni conexión a Internet. Conserva la carpeta assets junto a index.html para que el atlas lunar local esté disponible; no carga recursos de Internet.

## Publicar en GitHub Pages

Sube el contenido de esta carpeta a un repositorio de GitHub y activa GitHub Pages desde la rama principal, usando la carpeta raíz (/). La copia local seguirá funcionando sin conexión.

## Precisión

Las fases y los horarios se calculan en el navegador con fórmulas astronómicas aproximadas. La salida y puesta de la Luna pueden diferir varios minutos por el horizonte local y las diferencias entre los modelos y datos astronómicos de referencia. El fondo muestra estrellas brillantes de un catálogo reducido alrededor del cenit y gira con la hora local; es una representación aproximada, no sustituye un planisferio de precisión. La lista de eclipses está basada en las predicciones de Fred Espenak, NASA GSFC, para 2027–2030.
